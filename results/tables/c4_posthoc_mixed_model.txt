=== C4 POST-HOC SENSITIVITY ANALYSIS (non-pre-registered) ===
Primary, pre-registered C4 analysis (chi-squared, independent counts) is in
statistical_tests.txt / 03_analysis.R.

Method: GEE (geepack::geeglm), cluster = CASE (each case's full set of
variant x model observations is one cluster), exchangeable working
correlation, robust (sandwich) standard errors. This covers both layers of
non-independence in this design -- the same variant scored by all three
models, and multiple variants sharing a case -- within one cluster, so
robust SEs are valid without requiring either correlation to be estimated
exactly right.
